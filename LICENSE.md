# License Information

## FlexLM License Server

This Docker container is designed to run a FlexLM license server. The FlexLM software itself is proprietary and this container only provides a wrapper around it.

## Requirements

To use this container, you need to provide:

1. A valid FlexLM license file (`license.dat`)
2. The appropriate vendor daemon for your software
3. Proper network configuration (hostname, MAC address)

## License Compatibility

This container is compatible with FlexLM licenses from various vendors. See the README.md for more information on compatible vendors.

## Usage Disclaimer

Ensure that your use of the FlexLM license server complies with the terms and conditions of the software license agreement with your vendor.
